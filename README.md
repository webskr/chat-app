# Vegarm - Development Guide

## Local Development with Ngrok

To test the application on physical devices or via a public URL, you can use **ngrok**.

### Prerequisites
- [ngrok](https://ngrok.com/) installed and authenticated.

### Steps to Setup

1.  **Start the Backend Servers**:
    - Ensure your Apache server (XAMPP) is running for the PHP backend.
    - Start the Node.js socket server:
      ```bash
      npm run socket-server
      ```

2.  **Start Ngrok**:
    - Open a new terminal and run:
      ```bash
      ngrok http 80
      ```
      *(Replace `80` with your local web server port if different)*

3.  **Update Frontend Configuration**:
    - Copy the `Forwarding` URL generated by ngrok (e.g., `https://your-ngrok-url.ngrok-free.app`).
    - Open the `.env` file in the root directory.
    - Set `EXPO_PUBLIC_BACKEND_URL` to your ngrok URL:
      ```env
      EXPO_PUBLIC_BACKEND_URL=https://your-ngrok-url.ngrok-free.app/chat-app/backend
      ```

4.  **Restart Expo**:
    - Clear the cache and restart the Expo development server:
      ```bash
      npx expo start -c
      ```

### Troubleshooting
- **Multi-Device Support**: A single ngrok tunnel can handle multiple devices (phones, emulators) simultaneously. As long as the `.env` in your project points to the active ngrok URL, any device running that build of the app will connect.
- **Socket Connection**: If the socket server (port 3000) is not reachable via the same ngrok tunnel, you may need a separate ngrok tunnel for port 3000 or use a service that supports multi-port tunneling.
- **CORS Issues**: The backend is configured to allow all origins in development mode. If you encounter CORS errors, ensure `backend/includes/db_connection.php` correctly sets the headers.
